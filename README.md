# ⚡ TG-CLI — Современный Telegram CLI клиент

> Старый `telegram-cli` (vysheng), на который до сих пор ссылаются на официальном сайте Telegram, умер ещё около 10 лет назад: он использует древний протокол MTProto 1.0, не поддерживает современную авторизацию, крашится на реакциях/стикерах/2FA и не компилируется на современных системах.
> 
> **TG-CLI** — это полноценная, быстрая и надежная замена на базе современного MTProto (Telethon + Rich + Prompt Toolkit + Typer), созданная для разработчиков, сисадминов и любителей работать в терминале.

---

## 🚀 Основные фичи

- **Вход без геморроя**:
  - 📷 **QR-код прямо в терминале** (`tg login` или `tg login --qr`) — сканируешь камерой смартфона (Настройки -> Устройства -> Подключить устройство) и ты внутри за 3 секунды. Никаких SMS!
  - 📱 По номеру телефона + коду авторизации + облачному паролю (2FA).
  - 🤖 По токену бота (`tg login --bot-token <TOKEN>`).
- **Интерактивный чат в терминале** (`tg chat <peer>`):
  - Полнодуплексный режим: новые сообщения прилетают в реальном времени, внизу удобная строка ввода.
  - Поддержка команд прямо в чате: `/file <путь>`, `/history [N]`, `/clear`, `/exit`.
- **Живой мониторинг (tail -f)** (`tg stream`):
  - Стриминг входящих сообщений со всех чатов или конкретного канала в реальном времени.
- **Отправка и пайпинг (Unix-way)**:
  - `tg send <кому> "текст"`
  - `echo "Бэкап готов!" | tg send me`
  - `cat error.log | tg send @admin`
- **Файлы и медиа**:
  - `tg send-file <кому> <файл> --caption "Подпись"` (с живым прогресс-баром загрузки).
  - `tg download <откуда> <id_сообщения>` (скачивание фото, войсов, документов, стикеров).
- **Списки и история**:
  - `tg chats` — таблица диалогов с разметкой типов (👤 ЛС, 👥 Группы, 📢 Каналы, 🤖 Боты), именами, юзернеймами и бейджами непрочитанных.
  - `tg read <кому>` — просмотр истории с временем, авторами, вложениями и реплаями.
- **Скриптинг и автоматизация**:
  - Флаг `--json` у большинства команд для легкого парсинга через `jq` или интеграции в скрипты.
- **Мультиаккаунты и сессии**:
  - Флаг `--session work` для переключения между личным и рабочим аккаунтом.

## 🛠 Быстрый старт

Утилита уже установлена и доступна в PATH под командой `tg` (или `tgcli`):

```bash
# 1. Авторизация (выбираем QR-код, телефон или бота):
tg login

# 2. Проверить текущий аккаунт:
tg me

# 3. Посмотреть последние диалоги:
tg chats

# 4. Отправить сообщение себе в Избранное (Saved Messages):
tg send me "Тестовое сообщение из CLI"

# 5. Зайти в интерактивный терминальный чат с пользователем:
tg chat @username
```

## 📖 Справочник команд

### 1. Авторизация и профиль
```bash
# Интерактивный вход (выбор QR / Телефон / Бот)
tg login

# Быстрый вход по QR-коду (ASCII QR прямо в консоли)
tg login --qr

# Вход по номеру телефона
tg login -p +79991234567

# Вход как Telegram Bot
tg login --bot-token 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

# Показать информацию о текущем пользователе
tg me
tg me --json

# Выйти из аккаунта и удалить сессию
tg logout
```

### 2. Список диалогов (`chats`)
```bash
# Показать последние 20 чатов
tg chats

# Показать только чаты с непрочитанными сообщениями
tg chats --unread

# Фильтрация по типу (user, group, channel, bot)
tg chats --type channel --limit 50
tg chats --type user

# Поиск по названию или @username
tg chats --search "Разработка"

# Вывод в JSON
tg chats --json
```

### 3. Чтение сообщений (`read`)
В качестве адресата (`peer`) можно указывать:
- `me` — Избранное (Saved Messages)
- `@username`
- Название чата или имя контакта
- Номер телефона `+7...`
- Числовой ID чата/пользователя (`123456789`, `-100...`)

```bash
# Прочитать последние 20 сообщений из Избранного
tg read me

# Прочитать последние 50 сообщений из чата
tg read @durov --limit 50

# Вывод сообщений в формате JSON
tg read @channel --json
```

### 4. Отправка сообщений (`send`)
```bash
# Обычное сообщение
tg send @username "Привет, как дела?"

# Отправка себе в Избранное
tg send me "Купить молоко, хлеб, кофе"

# Ответ на конкретное сообщение (reply)
tg send @chat "Согласен" --reply-to 14205

# Тихая отправка (без звукового уведомления)
tg send @user "Не срочно" --silent

# Отправка через STDIN (pipe)
echo "Сборка завершена успешно" | tg send me
git status | tg send me
cat /var/log/nginx/error.log | tg send @admin
```

### 5. Отправка и скачивание файлов (`send-file`, `download`)
```bash
# Отправить файл с прогресс-баром
tg send-file @username ./report.pdf --caption "Держи отчет"

# Отправить как документ без сжатия
tg send-file @username ./photo.jpg --doc

# Скачать вложение из конкретного сообщения
tg download @username 4521

# Скачать в конкретную папку или файл
tg download @username 4521 --out ./downloads/file.zip
```

### 6. Интерактивный терминальный чат (`chat`)
```bash
tg chat @username
```
- Загружает последние сообщения чата.
- Все входящие сообщения отображаются в реальном времени.
- Ввод сообщений через prompt-toolkit с историей.
- Команды внутри чата:
  - `/file <путь> [подпись]` — отправить файл
  - `/history [N]` — показать последние N сообщений
  - `/clear` — очистить экран
  - `/exit` — выйти из чата

### 7. Стриминг сообщений (`stream`)
Аналог `tail -f` для Telegram:
```bash
# Слушать все входящие сообщения со всех доступных чатов
tg stream

# Слушать только конкретный канал или пользователя
tg stream --peer @breakingmash

# Передавать новые сообщения в формате JSON в реальном времени
tg stream --json | jq .
```

### 8. Поиск по сообщениям (`search`)
```bash
# Глобальный поиск по всем диалогам
tg search "сервер упал"

# Поиск внутри конкретного чата
tg search "пароль" --peer me
```

### 9. Конфигурация (`config`)
```bash
# Посмотреть текущую конфигурацию
tg config

# Указать свои api_id и api_hash (с https://my.telegram.org)
tg config --api-id 1234567 --api-hash 0123456789abcdef0123456789abcdef

# Изменить папку для скачиваний по умолчанию
tg config --downloads-dir "D:\TG_Downloads"
```
